# Portfolio/Blog

My personal portfolio website showcasing my software development work, projects, experience, and creative background. 

Built with **Astro** and designed with a focus on performance, responsive layouts, and a custom editorial-inspired aesthetic.

## Tech Stack

- Astro
- TypeScript
- CSS
- Astro Content Collections
- Netlify / GitHub Pages deployment

## Features

- Resume and professional experience
- Project case studies and write-ups
- About page highlighting my journey from musician to developer
- Responsive, custom-designed layouts
