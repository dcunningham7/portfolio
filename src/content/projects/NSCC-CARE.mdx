## CARE

### Overview

**Clinical Assessment Record Entry (CARE)** is a clinical training application built to replace paper-based 
documentation used by continuing care and long-term care nursing students during simulated clinical sessions.

The application needed to model real clinical workflows: patient profiles, bed assignments, shift handoffs, 
and structured assessments, while remaining practical to use on tablets. It needed to be 100% compliant, 
and work every time.

I joined the project as a frontend developer on a six-person team and eventually took on much of the frontend 
leadership.

### My Role

I owned the visual direction and helped turn early prototypes into a reusable React interface. I worked closely 
with nursing faculty to understand how the application would actually be used, then translated that feedback into 
Figma designs, reusable components, patient profile builders, and multi-step clinical workflows.

I also worked across the frontend/backend boundary, coordinating API contracts and troubleshooting issues against 
the live application. The project was deployed through GitHub Actions and Azure.

### Designing for Real Users

One of the biggest lessons was that a technically sound interface can still be wrong for its users. 

Working with faculty exposed problems that weren't obvious from the original requirements. Tablet use, for example, 
changed how forms, navigation, and information density needed to work. In my initial designs I made a lot of assumptions
based on style, and was given feedback that the assessment forms would be completed on tablet almost all the time.

We iterated on the designs based on actual feedback rather than treating the original specification as fixed.

### Working as a Team

This was my first experience contributing to a larger development team.

I collaborated with five other developers across frontend and backend work, worked directly with faculty stakeholders, and mentored three student developers on Git workflows and code reviews.

It taught me how much good software development depends on communication between people, not just communication between systems.

### Results

The MVP expanded from an early prototype into an application used by 500+ nursing students and faculty.

Our team also presented the MVP to stakeholders, helping secure continued funding and a production pilot.

I was awarded [Student of the Year for the 2024–2025](https://www.nscc.ca/about/news/stories/2025/2024-co-op-and-wil-students-of-the-year.asp) academic year in recognition of my technical contribution to the project.


### What I Learned

CARE taught me to think about frontend development as more than building components.

The best implementation starts with understanding the person using it, communicating clearly with the people building it, and being willing to throw away an idea when the evidence says it's wrong.

It was also the project that made me realize I really enjoy building software with other developers.
